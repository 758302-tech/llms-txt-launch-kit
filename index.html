LLMS.txt Launch Kit

Generate and validate clean AI-friendly context files from URL lists, local Markdown, or sitemaps.

GitHub sample View llms.txt 
python3 tools/llms_kit.py generate \
  --title "Acme SaaS" \
  --description "Acme helps teams ship docs." \
  --url-list examples/url-list.txt \
  --output-dir public

python3 tools/llms_kit.py validate public/llms.txt

Local CLI

No API key. Generate from URL lists, local Markdown, or a sitemap, then validate before publishing.

Reviewable

Plain files. Keep the workflow local and inspect every URL before anything goes live.
